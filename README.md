# 像素勇者：无尽波次

横版 2D 像素风打怪升级小游戏。TypeScript + React（界面）+ Canvas（游戏画面）。

## 怎么玩

### 方式一：直接双击打开（推荐给只想玩的场景）

```bash
npm install
npm run build
```

构建完成后会生成 `dist/index.html`，**双击用浏览器打开即可玩**，不需要起服务器（所有代码和样式都内联在这一个文件里）。

### 方式二：开发模式（改代码实时热更新）

```bash
npm install
npm run dev
```

浏览器打开终端里输出的地址（默认 http://127.0.0.1:5173）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 / 二段跳（空中再按一次） | `空格` / `W` / `↑` / `K` |
| 普攻挥砍 | `J` / `X` |
| 技能1 回旋斩（原地转圈砍周围） | `U` / `1` |
| 技能2 冲锋（冲刺期间无敌） | `I` / `2` |
| 技能3 治疗回血 | `O` / `3` |
| 暂停 / 继续 | `Esc` / `P` |
| 选择升级加成 | `1` `2` `3` 或鼠标点击 |

## 玩法要点

- 怪物一波一波来，每波更强（数量、血量、伤害、速度随波次成长）。
- 三种怪：绿皮哥布林（普通追击）、狂暴小鬼（伤害极高但很脆，动手前会站起来发红光并显示“!”）、肥壮巨怪（很肉、走得慢、伤害低）。
- 击杀获得经验，升级时血量上限与攻击提升、血量回满，并从 3 个随机加成中选 1 个。
- 暂停、升级选卡、波次结算期间时间冻结，无法攻击。
- 进度自动保存到浏览器 localStorage，关掉再打开可以「继续游戏」。
- 切换到别的程序会自动暂停，切回来有 3 秒准备时间。

## 代码结构（按职责拆模块）

```
src/
  engine/      引擎核心（与具体玩法无关）：定点游戏循环、输入、AABB 物理、对象池、随机数、事件、快照存储
  game/        游戏内容：角色、怪物、技能、伤害判定、波次、升级、关卡地形、特效、存档
  render/      游戏画面：Canvas 渲染器、像素精灵（程序化像素图 + 离屏缓存）、视差背景
  ui/          React 界面：HUD、技能栏、血条、升级三选一、暂停/结算/失败面板
  hooks/       React 与引擎之间的桥（生命周期、失焦暂停、快照订阅）
```

存档键：`gsb-b.save.v1`（localStorage）。想清空进度可以在开始界面点「清空存档」，
或者在浏览器开发者工具里删除该键。

## 开发工具

```bash
npm run typecheck   # TypeScript 类型检查
npm run simulate    # 无头模拟：用真实引擎跑 8 波战斗，校验波次/升级/暂停冻结/生成点/内存池/存档
```

`npm run simulate` 会把一个「会走位、会用技能」的机器人放进游戏里跑，并在每一步检查这些不变式：
怪物不会生成在墙里、不会叠在同一个位置、粒子与飘字不会超过对象池上限、暂停与升级选卡期间时间与怪物完全冻结、
波次结算时场上没有怪、存档能被正确读回。任何一条不满足都会以非 0 退出码报错。
